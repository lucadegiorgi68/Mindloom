# Behaviour spec (clean room)

Written from the reference screenshots, describing what a user can do and see,
in our own words. No third party code, icons, illustrations or fonts are used.
Visual identity (palette, frame artwork, icon, name) is original.

## Creating a map
1. Name the map, then choose the starting point (mind map first; task board and
   whiteboard are later phases).
2. Optional start modes: blank map, idea generation (AI, later), combine maps,
   import.
3. Pick a central idea frame. Frames are hand drawn marker outlines in several
   colours and shapes (box, speech bubble, cloud, filled variants), or a custom
   image.

## Canvas
* The central idea shows green plus handles at its left and right sides; they
  add branches. A "..." button opens a context menu: undo, redo, clean up,
  cut, copy, paste, copy branch link, select, add, format, export, delete, AI.
* A new branch starts as an empty editable box connected by a curved line.
* While editing text a format bar offers: font, size, bold, italic, underline,
  alignment, colour, shape, line style, add image, done.
* The add tool offers: box (with 12 frame shapes), branch (with 10 stroke
  styles such as tapered, dotted, arrow, dashed, wavy, zigzag), freehand, and
  auto inherit (new items copy the style of the previous one).
* Branches are organic: thick at the parent, tapering toward the tip, with
  control points to bend them by hand.
* Branches can carry a small task check mark and a label that follows the curve.

## Display options
View (mind map, task board, whiteboard), dyslexia mode, large controls, map
theme, auto layout, control points, auto focus (off, on, on plus), branch
thickness, branch label colour, shadows, background, dark mode, creators,
speed keys.

## Board options
Name, description, save as template, folder, archive, navigation settings,
duplicate, delete.
